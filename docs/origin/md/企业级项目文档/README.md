## 适用范围

HR Agent 是一个面向企业 HR 场景的智能人力资源管理系统，当前项目覆盖：

- HR Agent 对话入口与 LangGraph 受控编排（生成、修改、删除、邮件草稿、多轮指代）
- JD 生成、评分标准生成、简历筛选、面试方案生成
- 智能面试：腾讯会议建会、音视频/文档转写、问答配对、四维评分、人工修订
- 试卷生成、考试管理与结果查看
- 文档上传、知识库管理、知识问答
- 用户登录、角色管理、邮箱配置、统计看板

## 编写口径

- 以当前 FastAPI 后端、Vue 3 前端、PostgreSQL + pgvector、LangGraph 编排、Dify 工作流、LLM/RAG 服务、腾讯会议 MCP 为依据。
- JD、评分标准、面试方案由远程 HR 服务持久化，本系统不建这三张表；数据字典已按此口径更新。
- 不将系统描述为完整 ATS、HRIS 或全自动招聘决策平台。
- 将 CI/CD、集中监控、服务发现等平台能力作为上线前置或运维协作项，不默认视为本项目代码已内建能力。
